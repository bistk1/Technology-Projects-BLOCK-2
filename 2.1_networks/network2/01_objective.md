
## 📘 1. Objective (In Your Own Words)
Briefly describe the purpose of this lab.  
What were you trying to achieve?


The purpose of this lab is to learn how to configure and use DHCP and DNS servers in a computer network. I was trying to configure the DHCP server to automatically assign IP addresses to computers and set up the DNS server to translate domain names into IP addresses. I also wanted to test whether the network devices could communicate successfully.
