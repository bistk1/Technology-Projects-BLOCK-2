
## 🗺️ 2. Network Topology Setup

### 2.1 Description  
Explain how you built the network topology (devices, cabling, layout).

For this activity I used one server and three PCs, and connected them with one switch, for network topology simulation in Cisco Packet Tracer. All devices could now communicate, with the server providing the DHCP and DNS services to the three PCs which acted as the client devices. This setup gave me some great hands on experience and insight on the client server architecture of networking.
