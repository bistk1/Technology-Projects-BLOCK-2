
## 🗺️ 2. Network Topology Setup

### 2.1 Description  
Explain how you built the network topology (devices, cabling, layout).

### Description

I created the network topology using Cisco Packet Tracer. I added PCs, a switch and a server to the workspace. I connected the devices to the switch using Ethernet cables. The server was used to configure DHCP and DNS services. The PCs were connected to the same network so they could receive IP addresses automatically and communicate with the server.
