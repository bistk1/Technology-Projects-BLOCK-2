
## 🧠 6. Reflection

Answer in full sentences:

1. What are the advantages of DHCP over static IP assignment?
DHCP makes network configuration easier because it automatically assigns IP addresses to devices. It saves time and reduces the chance of mistakes, as we do not need to enter the IP settings manually on every PC.

2. How does DNS improve usability in a network?
DNS makes a network easier to use because users can access devices or services using names instead of remembering IP addresses. It automatically converts the hostname into the correct IP address.

3. What would happen if the DHCP server went offline?
If the DHCP server went offline, new devices might not receive IP addresses automatically. This could make it difficult for them to connect to the network. Devices that already have an IP address may continue working until their DHCP lease expires.

4. Optional: What part of this activity did you find easy or challenging? Why?
I found connecting the PCs and configuring DHCP quite easy after understanding the steps. However, configuring DNS and checking the network using ping and ipconfig commands was a little challenging at first. This activity helped me understand how DHCP and DNS work in a network.
