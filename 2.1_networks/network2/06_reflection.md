
## 🧠 6. Reflection

Answer in full sentences:

1. What are the advantages of DHCP over static IP assignment?  
DHCP makes network configuration easier because it automatically assigns IP addresses to computers. It saves time and reduces the chance of IP address conflicts. We do not need to configure every PC manually.

2. How does DNS improve usability in a network?  
DNS makes a network easier to use because it converts domain names into IP addresses. Users can access devices and servers using names instead of remembering long IP addresses.

3. What would happen if the DHCP server went offline?  
If the DHCP server went offline, new devices might not receive IP addresses automatically. Existing devices with valid IP addresses may continue communicating, but new network connections could have problems.

4. Optional: What part of this activity did you find easy or challenging? Why?
I found enabling DHCP and DNS services quite easy after understanding the settings. However, configuring the DHCP pool and DNS records was a little challenging at first. This activity helped me understand how servers manage network configuration.
