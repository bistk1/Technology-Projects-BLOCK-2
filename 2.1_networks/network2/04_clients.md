
## 💻 4. PC Configuration (DHCP Clients)

### 4.1 Explanation  
Describe how you configured PCs to obtain addresses automatically.

I configured the PCs to obtain IP addresses automatically by selecting DHCP in the IP Configuration settings. The PCs sent requests to the DHCP server, which automatically assigned them IP addresses and other network settings such as the subnet mask, default gateway and DNS server.
