## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?
If two PCs have the same IP address, an IP address conflict will happen. This can cause network connection problems, and the PCs may not communicate properly.

### 5.2 Why do we use a switch instead of directly connecting PCs together?
We use a switch because it connects multiple PCs in one network. It allows all connected computers to communicate with each other easily without needing separate direct connections.

### 5.3 What does the subnet mask 255.255.255.0 indicate?
The 255.255.255.0 subnet mask indicates that the first three sections of an IP address provide network information and the fourth section provides device-specific information. Devices on the same network can also communicate using this mask.
