## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?

If two PCs had the same IP address, an IP address conflict would occur. This could cause network communication problems, and the computers might not communicate properly.

### 5.2 Why do we use a switch instead of directly connecting PCs together?
We use a switch because it connects multiple computers in one network and allows them to communicate with each other easily. It also sends data to the correct device.

### 5.3 What does the subnet mask 255.255.255.0 indicate?


The subnet mask 255.255.255.0 means that the first three parts of the IP address identify the network, while the last part identifies the individual device. It allows devices in the same network to communicate with each other.
