## 📘 1. Summary of the Task
Describe the purpose of this activity in your own words:  
- What is the goal of the lab?  
- What network are you expected to create?


The goal of this lab is to learn how to create a basic computer network using Cisco Packet Tracer. I am expected to create a network with five PCs connected to a switch. I will configure IP addresses for each PC and test whether all the computers can communicate with each other using the ping command.
